## Status

Not locked yet.

## Working Gap Candidate

Most static-threshold or generic intelligent-irrigation controllers do not sufficiently evaluate phenology-specific dynamic soil-moisture target bands for paddy rice under reproducible closed-loop simulation. This project tests whether a phenology-aware fuzzy controller can improve the tradeoff between irrigation water use, dynamic target-band tracking, and yield-oriented outcomes compared with static/reactive baselines.

## Novelty Risk

- The dynamic target bands must be justified as experiment-design parameters if exact universal values are not available from literature.
- If fuzzy logic itself is standard, the stronger contribution may be the phenology-aware control formulation and evaluation protocol, not a new fuzzy algorithm.
- Any water-saving or yield claim must come only from verified simulation results.
